# Excalidraw demo — Linear location

Use this to make sure Excalidraw demo work goes to the correct Linear workspace/team/project.

## Team (this sets the issue key)

- **Team:** Excalidraw Demo

- When creating an issue, set the team to **Excalidraw Demo** so it gets an `EXCAL-` key. Issue keys are per-team, not per-project.
